HMPRO + EGCO
ไล่ราคาก่อนขึ้น XD

รวมแหล่งข่าวทางการ วิธีอ่านมติบอร์ด เกณฑ์เข้า-ออก และบทเรียนปี 2568 ไว้ที่เดียว กลยุทธ์นี้คือ ซื้อหลังประกาศปันผล แล้วขายวันทำการสุดท้ายก่อน XD ไม่ได้เก็บเงินปันผล

อัปเดต 14 ส.ค. 2569 ตัวหลัก: HMPRO ตัวสำรอง: EGCO ขายวันก่อน XD GitHub Pages ฟรี
วิธีใช้หน้านี้ แผนเข้า-ออก แหล่งข่าวทางการ อ่านข่าว SET ตั้งแจ้งเตือน ข้อมูลปีที่แล้ว สิ่งที่ต้องเฝ้าตอนนี้

วิธีใช้หน้านี้ใน 2 นาที

  1. ตอนนี้ยังไม่ต้องซื้อ เปิดหน้าข่าว SET ของ HMPRO และ EGCO ทุกวันหลังตลาดปิด ประมาณ 17:00–20:00
  2. รอข่าวหัวข้อ “การจ่ายปันผล” หรือ “มติคณะกรรมการ” อ่านแค่ 4 ช่อง: จำนวนเงินต่อหุ้น, วัน XD, วัน Record, วันจ่าย
  3. เข้าได้เมื่อตัวเลขไม่ต่ำกว่าเกณฑ์ HMPRO ใกล้ 0.16 บาทขึ้นไป · EGCO ยังได้ 3.25 บาท
  4. ขายวันทำการสุดท้ายก่อนวัน XD อย่าถือข้ามวัน XD เพราะกลยุทธ์นี้ไม่ได้ต้องการเงินปันผล

แผนเข้า-ออก

HMPRO ตัวลุ้นกำไรสูงสุด

ปีที่แล้ววิ่งจาก 7.05 → 7.85 บาท ระหว่าง 14 ส.ค. ถึงวันก่อน XD คิดเป็น +11.3%

  • เข้าหลังประกาศ DPS ไม่ต่ำกว่า 0.16 บาท
  • ถ้าวอลุ่มไม่มาหลังประกาศ อย่าฝืนถือ
  • ขายวันทำการก่อน XD

EGCO ตัวที่สม่ำกว่า

ปีที่แล้ววิ่งจาก 113 → 117 บาท ในช่วงเดียวกัน คิดเป็น +3.5% ยีลด์รอบนั้นสูงกว่าแบงก์ใหญ่ชัด

  • เข้าหลังประกาศ DPS ยังเป็น 3.25 บาท
  • ถ้าตัดปันผลลง ยกเลิกไม้สั้นนี้
  • ขายวันทำการก่อน XD
อย่าซื้อแบงก์ใหญ่ด้วยกลยุทธ์นี้ ปีที่แล้ว BBL และ SCB ซื้อช่วงนี้แล้วยังติดลบก่อน XD เพราะปันผลรอบกันยายนบางเกินไป คนไม่ไล่ราคา

แหล่งข่าวทางการ เปิดอันนี้ก่อน

HMPRO

ข่าว SET ของ HMPRO ต้นทางมติบอร์ดและข่าวปันผล สิทธิประโยชน์ / วัน XD ดูวัน XD และวันจ่ายหลังข่าวออก ข่าวแจ้งตลาดจากเว็บบริษัท สำเนาข่าว SET ฝั่ง IR นโยบายปันผล HMPRO จ่ายไม่น้อยกว่า 40% ของกำไรสุทธิ ir@homepro.co.th

EGCO

ข่าว SET ของ EGCO ต้นทางมติบอร์ดและข่าวปันผล สิทธิประโยชน์ / วัน XD ดูวัน XD และวันจ่ายหลังข่าวออก ปฏิทินนักลงทุนสัมพันธ์ วันประกาศงบ / พบนักวิเคราะห์ สมัครอีเมลข่าว EGCO เลือก Disclosure + Financial Statement หน้า IR หลักของ EGCO

วันที่ไม่ได้รับสิทธิปันผล (XD) วันแรกที่ซื้อแล้วไม่ได้ปันผล ขายวันทำการก่อนหน้านี้
