# HMPRO + EGCO — คู่มือไล่ราคาก่อน XD

หน้าเว็บส่วนตัวสำหรับติดตามข่าวปันผลและวัน XD ของ **HMPRO** กับ **EGCO**

- เปิดใช้ฟรีด้วย [GitHub Pages](https://pages.github.com/)
- ไม่มีเซิร์ฟเวอร์ ไม่มีค่าใช้จ่าย
- ข้อมูลจริงมาจากข่าว SET และเว็บ IR ของบริษัท

## เปิดหน้าเว็บ

หลังเปิด GitHub Pages แล้ว เข้าได้ที่

**https://bigbenmaths.github.io/hmpro-egco-xd/**

## แก้หน้าเว็บแล้วอัปเดต

แก้ไฟล์ `index.html` แล้วรัน

```bash
cd ~/hmpro-egco-xd
git add index.html
git commit -m "Update page"
git push
```

อีกประมาณ 1 นาที หน้าเว็บจะอัปเดตเอง
